# GRINTA - Backend (Spring Boot)

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Mustapha-who/Grinta-springboot.git
cd Grinta-springboot
```

### 2. Install dependencies

**IntelliJ IDEA:**
- Open the project
- Click the Maven icon → `Reload All Maven Projects`

**VS Code / Terminal:**
```bash
mvn install
```

### 3. Run the project

**IntelliJ IDEA:**
- Click the green ▶ Run button

**VS Code / Terminal:**
```bash
mvn spring-boot:run
```

The server will start at `http://localhost:8000`

> ⚠️ Make sure MySQL is running on port `3300` with a database named `sport` before starting the app.
